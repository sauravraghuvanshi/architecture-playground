# Asset licensing

This document describes the project's conservative asset policy. It is not legal advice.

## Bundled Whiteboard symbols

Diagrammatic ships 600 general-purpose symbols generated from [Lucide](https://lucide.dev/). Lucide is distributed under the ISC license; a subset derived from Feather is MIT licensed. The required notices are retained in [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

The bundled catalog intentionally avoids community libraries and third-party
logo collections. Whiteboard does not expose external library catalogs, library
URL imports, or upstream scene imports.

## Cloud provider architecture icons

Azure, AWS, and Google Cloud service icons are vendor-owned assets and are not relicensed by Diagrammatic. They are provided for architecture-diagram use with provider attribution. Users should follow the current provider guidelines:

- [Microsoft Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/)
- [AWS architecture icons](https://aws.amazon.com/architecture/icons/)
- [Google Cloud icons](https://cloud.google.com/icons)

Do not use provider icons to imply endorsement or represent Diagrammatic itself.

## Embedded Excalidraw

The embedded `@excalidraw/excalidraw` package is MIT licensed. Its notice is retained in [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
